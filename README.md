## Featured Projects

### 1. KRATOS — Industrial Thermal Intelligence & Geospatial Risk Assessment

An AI-assisted geospatial intelligence platform that combines satellite thermal observations, industrial infrastructure data, statistical anomaly detection, and evidence-grounded investigation workflows.

- Integrates NASA FIRMS satellite observations with OpenStreetMap infrastructure and geospatial data.
- Uses PostgreSQL and PostGIS for spatial data management and proximity analysis.
- Combines Isolation Forest, robust statistical deviation (MAD), and CUSUM change detection for thermal anomaly assessment.
- Includes a React and TypeScript interface, Flask APIs, investigation reporting, and a Gemini-powered AI investigator.

**Stack:** Python · Flask · React · TypeScript · PostgreSQL · PostGIS · Scikit-learn · NASA FIRMS · OpenStreetMap · Docker

[View KRATOS repository](https://github.com/omkarchoudhary29/kratos-industrial-thermal-intelligence)

### 2. MarketPath AI — Omnichannel D2C Commerce Platform

An AI-assisted commerce operating platform designed to help D2C brands manage product catalogues, channel listings, orders, inventory, marketing workflows, and business operations from one place.

- Builds a unified product catalogue and channel-specific listing workflow.
- Uses Google Gemini to support brand-aware listing and marketing content generation.
- Includes channel publishing safeguards, order and inventory workflows, growth analytics, and agency/consultant collaboration modules.
- Designed with a React and TypeScript frontend, Python FastAPI backend, and Railway deployment.

**Stack:** Python · FastAPI · React · TypeScript · Tailwind CSS · Google Gemini · Railway

[View MarketPath AI repository](https://github.com/omkarchoudhary29/MarketPath-AI)

### 3. Enterprise Knowledge Navigator — PDF Intelligence & RAG

An enterprise document intelligence platform for searching and reasoning over technical manuals, operating procedures, specifications, and compliance documents with evidence-backed answers.

- Supports document ingestion, PDF extraction, selective OCR, hierarchical chunking, and indexing.
- Combines dense vector retrieval with BM25 keyword search and cross-encoder reranking.
- Uses ChromaDB, Sentence Transformers, LangChain, and LangGraph in the retrieval and conversational workflow.
- Provides source-grounded answers with document and page-level citations, document version comparison, and knowledge graph capabilities.

**Stack:** Python · FastAPI · Streamlit · ChromaDB · Sentence Transformers · BM25 · LangChain · LangGraph · PyMuPDF · Tesseract OCR · Docker

[View PDF Intelligence repository](https://github.com/omkarchoudhary29/PDF-Intelligence)
