I am an **Artificial Intelligence and Data Science engineering student** at **Nutan Maharashtra Institute of Engineering & Technology (NMIET), Pune** (Batch of 2028), holding a current **CGPA of ~8.80/10**.

### 🛡️ [FraudShield AI — Real-Time Fraud Detection & Risk Intelligence](https://github.com/omkarchoudhary29/FraudShield_AI)
> An end-to-end, full-stack fraud monitoring system combining machine-learning anomaly detection with analyst-facing investigation workflows.
- **Machine Learning Core:** Ensemble scoring combining **XGBoost** for supervised fraud pattern classification and **Isolation Forest** for unsupervised anomaly detection.
- **Explainable AI (XAI):** Integrated **SHAP** values to provide transaction-level feature importance attribution, giving risk analysts transparent reasoning for every flagged score.
- **Real-Time Architecture:** Asynchronous streaming via **FastAPI** and **WebSockets**, persisting telemetry into **MongoDB** with audit trail records.
- **Stack:** `Python` • `FastAPI` • `React` • `MongoDB` • `XGBoost` • `SHAP` • `scikit-learn` • `WebSockets`

<br/>

### 📄 Enterprise PDF Knowledge Engine (Intel® Unnati)
> An intelligent document extraction pipeline transforming unstructured enterprise documents and PDFs into searchable semantic knowledge.
- Developed as part of the **Intel® Unnati Industrial Training Program (EdGate Technologies & Intel)** under faculty guidance.
- Implemented OCR pre-processing, text-region segmentation, and table understanding pipelines to extract high-fidelity structured data.
- Built an indexing layer to enable quick retrieval and query answering over enterprise documentation.
- **Stack:** `Python` • `OCR (Tesseract/EasyOCR)` • `NLP` • `Document Intelligence` • `FastAPI`

<br/>

### 🏠 HomelyHub — Full-Stack Property Booking Platform
> A production-ready, full-stack accommodation reservation application designed for seamless traveler and host experiences.
- Developed during the **Emertxe MERN Stack Internship** (certified by NSDC / ESSCI).
- Features dynamic property search, interactive filtering, state-driven booking flows, host listing management, and secure JWT authentication.
- **Stack:** `MongoDB` • `Express.js` • `React` • `Node.js` • `REST APIs`

<br/>

### 🧾 Smart Reimbursement System
> An OCR-driven intelligent expense tracking and automated receipt parsing system.
- Reads invoice and receipt images to auto-extract critical expenditure metadata (merchant, dates, line items, taxes, totals), eliminating repetitive manual entry.
- **Stack:** `Python` • `Computer Vision` • `OCR` • `Flask/FastAPI` • `JavaScript`
